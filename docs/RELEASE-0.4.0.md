# AI kit 0.4.0

本版交付目标：把依赖提示词和人工日志的研究协作，升级成可执行、可检查、可恢复的科研工具包。

- 增加证据绑定的七阶段门控、独立复核、撤销和过期处理。
- 增加研究调度官、复现审计官，共六类中英文专家。
- 增加 11 项研究任务契约和只读就绪计划。
- 加强统计登记与稿件数字审计，保留既有 R 格式兼容性。
- 加强安装清单校验、安全解包、备份回退和最小连接器配置。
- 新增失败场景测试，修正 README 对研究完成度的过度描述。

## 从 0.3.0 升级

保留旧版安装 ZIP、数据、统计结果和私有决策记录。解压新版，先运行 `install_kit.ps1 -VerifyOnly`；再按 `INSTALL.md` 安装选定语言。新版不会把旧的 Markdown “通过”记录自动转换成已验证审批。对需继续使用的历史门控，应提交现有证据并独立复核。

参数、策略和证据变化会使已有审批过期。这是重新审阅的信号，不是要求删掉历史研究，也不是把历史阴性结果改成阳性。

## 验证边界

工程验收与科学验收分开报告。Python 测试、安装包校验和临时目录中的离线安装可由本地自动检查；全新电脑上的应用安装、真实 Open-Science 模型会话和完整研究流水线需要分别验证。没有执行的项目应明确写成未测。

参见 `docs/ARCHITECTURE.md` 和技能中的 `references/governance.md`。
