# Marrow 视觉系统与作图规范

艺术性和实用性的统一靠一条原则：**同一个实体在所有图里永远是同一种颜色。**读者看到深红就知道是 CXCL11，看到青绿就知道是 CXCR3/T 细胞，看到紫色就知道是 ACKR3/内皮。

## 配色（唯一来源：`style/palette.json`）

| 实体 | 颜色 | 用途 |
|---|---|---|
| CXCL11 | `#c8243c` 深红 | 主角基因、高表达组、图形摘要里的趋化因子梯度 |
| CXCR3 / T 细胞 | `#00897b` 青绿 | CXCR3、CD8+ T 细胞 |
| ACKR3 / 内皮 | `#6a4fb8` 紫 | ACKR3、血管内皮 |
| 髓系 | `#c47f00` 琥珀 | 巨噬细胞、单核细胞 |
| 破骨细胞 | `#d0559a` 洋红 | |
| NK | `#4a9a2e` 绿 | |
| 成纤维细胞 / CAF | `#2f6db5` 蓝 | 低表达组也用这个蓝 |
| 成骨型肿瘤细胞 | `#a8662e` 赭 | |
| 其他 | `#b9b3a8` 骨灰 | 第 9 类及以后的细胞类型一律归入"其他" |

- **高/低两组**：深红 `#c8243c` 对蓝 `#2f6db5`。色盲模拟下色差 19.3，普通视觉下 29.3，区分度很高。
- **连续表达**（FeaturePlot、热图强度）：用 `os_seq`，从骨灰白过渡到深红。
- **相关性和 z-score**：用 `os_div`，蓝—骨白—深红，0 固定在中点。
- 配色已经通过色盲和对比度校验，结果记录在 `palette.json` 的 `validation` 字段。**不要临时添加新颜色。**

## 规则
- **字体**：Arial；最小 7 pt，面板标题 8 pt 加粗，面板字母 9 pt 加粗（a、b、c…）。
- **尺寸**：单栏 85 mm，1.5 栏 120 mm，双栏 180 mm；高度不超过 225 mm。
- **输出**：矢量 PDF（文字保留可编辑）加 600 dpi LZW TIFF。函数是 R 的 `os_save()` 和 Python 的 `save_figure()`。
- **线条**：坐标轴 0.3–0.4 pt，数据线 1 pt；网格只保留 y 方向的淡线。
- **散点和 UMAP**：超过 3 个类别时，必须在簇中心直接标注名称（类别多时颜色无法逐一两两区分）；点用 0.5–2 pt，可以半透明。
- **KM 曲线**：附风险人数表；HR 和 p 值用统计片段里的 display 值，不要手写。
- **森林图**：每个队列一行，最后一行是合并结果（菱形）；I² 写在图注里。
- **禁止**：双 y 轴、彩虹色、3D 饼图、无意义的阴影或渐变、生成式 AI 图像。

## 8 张主图的构成

1. **研究设计和图形摘要**：四轨并行汇合的流程图，加上骨皮质截面的机制示意（手工 SVG）。
2. **多队列预后**：各队列 KM 曲线、per-SD HR 森林图、meta 结果。
3. **Bulk 免疫微环境**：多算法浸润热图（`os_div`）、CD8/IFN-γ 相关性、冷热肿瘤分型。
4. **单细胞图谱**：UMAP（直接标注）、CXCL11 来源的点图（显示检出比例）、细胞通讯弦图或点图。
5. **CXCR3 与 ACKR3 的平衡**：受体在不同细胞中的分布、ABS 的分布、ABS 与 CXCL11 的交互效应、空间共定位（如有数据）。
6. **ML 模型**：嵌套 CV 结果、外部验证 C-index、SHAP 蜂群图、列线图和校准曲线。
7. **免疫治疗与药物**：TIDE/IPS、ICB 迁移验证的森林图（标注"间接证据"）、药敏结果。
8. **在线平台**：功能模块截图和架构示意。

## 图形摘要和机制图
- 用手工构建的 SVG（代码或 Inkscape 绘制），元素包括：骨皮质和骨小梁截面、肿瘤岛、CXCL11 浓度梯度（深红渐淡）、被招募来的 T 细胞（青绿）、清除趋化因子的血管（紫）。
- 背景用骨象牙白 `#faf7f0`；线条简洁，留足空白，信息层级清楚。
- 不使用需要授权的素材库（如 BioRender），除非用户已经购买并确认可以用于发表。
